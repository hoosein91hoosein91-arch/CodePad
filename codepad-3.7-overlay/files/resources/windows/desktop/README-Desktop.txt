CodePad 3.7 (AI + Cyber) - نسخهٔ دسکتاپ ویندوز
================================================

این یک برنامهٔ مستقل است: پنجرهٔ خودش را دارد (مثل بازی‌ها)، به مرورگر، Edge/Chrome، اینترنت یا پورت محلی نیاز ندارد و Chromium را همراه خودش دارد.

اجرا
1) کل پوشه را استخراج کن (مثلاً C:\CodePad). فایل CodePad.exe باید کنار بقیهٔ فایل‌ها بماند.
2) روی CodePad.exe دوبار کلیک کن.
3) F11: تمام‌صفحه / بازگشت · F5 یا Ctrl+R: بارگذاری دوباره · اجرا با CodePad.exe --fullscreen: شروع تمام‌صفحه.
4) بستن پنجره = بستن برنامه. اجرای دوباره همان پروژه‌ها را نشان می‌دهد؛ اجرای دوم هنگام باز بودن، پنجرهٔ قبلی را جلو می‌آورد.

نیازها: Windows 10/11 x64. حدود ۶۰۰ مگابایت فضا پس از استخراج.

هشدار SmartScreen: فایل امضای دیجیتال ندارد؛ ویندوز ممکن است «Windows protected your PC» نشان دهد: More info ← Run anyway.

داده‌ها: پروژه‌ها و تنظیمات در %APPDATA%\CodePad ذخیره می‌شوند. برای پشتیبان از «مرکز پروژه» داخل برنامه استفاده کن. برای پاک‌کردن کامل، پوشهٔ همین مسیر را حذف کن.

موسیقی (دکمهٔ ♪ پایین-راست)
- LOCAL: پوشهٔ Music\Phonk - Video Songs را خودکار می‌خواند (mp3, m4a, ogg, wav, flac, mp4, webm؛ mkv/avi/wmv قابل پخش نیستند). «انتخاب پوشه» مسیر را عوض می‌کند. زیرپوشه‌ها (تا ۴ سطح) هم خوانده می‌شوند.
- RADIO: ایستگاه‌های رادیوی فانک از radio-browser.info؛ «موزیک بعدی» ایستگاه را عوض می‌کند. برچسب‌ها: phonk، drift phonk، brazilian phonk، darksynth، synthwave، lofi. اینترنت لازم است.
- FOCUS: پلی‌لیست تمرکز برای کدنویسی. آهنگ‌هایی که در پوشهٔ تو باشند از همان پخش می‌شوند؛ بقیه با 🔎 در مرورگر جست‌وجو می‌شوند. فایل صوتی همراه برنامه نیست.
- مینی‌پلیر هنگام کدنویسی روی صفحه می‌ماند و موسیقی ادامه دارد.

نقشهٔ حملات سایبری: Cyber (بالا-چپ) ← ATTACK MAPS. شش نقشهٔ زنده (Kaspersky، Check Point، FortiGuard، Radware، Digital Attack Map، NETSCOUT) داخل خودِ پنجره باز می‌شوند. داده مال همان سایت‌هاست و اینترنت لازم است؛ اگر یکی بسته بود بعدی را بزن یا «↗ مرورگر».

تم: Cyber Lab ← دکمهٔ بالا (HYPER / THEME ON / THEME OFF) شدت تم هکری را عوض می‌کند.

جایگزین‌های ویندوزی چیزهایی که در اندروید مال گوشی‌اند (در اندروید همان قبلی‌ها می‌مانند)
- Termux ← PowerShell ویندوز: ترمینال Cyber Lab، تب ترمینال Studio، دستورهای termux/nmap/scan در لانچر و ابزار «فرمان» ایجنت همه در PowerShell اجرا می‌شوند و stdout/stderr/exitCode واقعی برمی‌گردد (غیرتعاملی). برای ترمینال تعاملی «PowerShell جدا» را بزن.
- CPython اندروید ← Python واقعی ویندوز (همراه برنامه، نسخهٔ ۳٫۱۳): برنامه‌هایی که فقط کتابخانهٔ استاندارد دارند (و هر برنامه‌ای که socket، sqlite3، thread و مانند آن می‌خواهد) با Python واقعی اجرا می‌شوند، با ورودی زنده، Stop، آرگومان و متغیر محیطی (Studio ← ترمینال). برنامه‌هایی که کتابخانهٔ نصب‌شده می‌خواهند (مثل numpy) مثل قبل به WebAssembly (Pyodide) می‌روند. ربات‌هایی مثل ربات بله حالا مستقیم داخل برنامه اجرا می‌شوند.
- Python همراه برنامه «embeddable» است: tkinter و pip ندارد. اگر کتابخانهٔ pip خودت را می‌خواهی، Python نصب‌شدهٔ خودت را بساز و مسیر python.exe را در Studio ← ترمینال بده و موتور را روی «Python واقعی» بگذار.
- ابزارهای دستگاه: «مکان» از سرویس Location ویندوز (باید در Settings ← Privacy روشن باشد)، «برنامه‌های نصب‌شده» از رجیستری ویندوز و بازکردن برنامه از Start Menu. نصب APK در ویندوز معنی ندارد.
- ابزارهایی مثل git و nmap همراه برنامه نیستند: winget install -e --id Git.Git و winget install -e --id Insecure.Nmap (دکمهٔ «نصب ابزارها» در Cyber Lab راهنما می‌دهد). اسکن nmap بدون Npcap/Administrator فقط -sT را پشتیبانی می‌کند.
- اتصال به «سرور AI من»: سرور باید هدر CORS برای codepad://app بدهد (Access-Control-Allow-Origin).
- دوربین (ردیابی دست) با اجازهٔ دوربین ویندوز کار می‌کند.

آزمایش‌شده: پنجره، پایتون واقعی (سوکت/sqlite/thread/input/Stop)، WebAssembly، پوستهٔ ویندوز، نمونه‌کد Cyber Lab، ماندگاری، پوشهٔ موسیقی و نقشهٔ داخل پنجره (آزمون دودی CI روی ویندوز واقعی + لینوکس). مکان و فهرست برنامه‌های ویندوز و open-app در CI آزمایش نمی‌شوند؛ آدرس سایت‌های نقشه و رادیو از این محیط قابل بررسی زنده نبود.

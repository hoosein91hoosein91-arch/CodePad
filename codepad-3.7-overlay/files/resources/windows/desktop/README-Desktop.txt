CodePad 3.7 (AI + Cyber) - نسخهٔ دسکتاپ ویندوز
================================================

این یک برنامهٔ مستقل است: پنجرهٔ خودش را دارد (مثل بازی‌ها)، به مرورگر، Edge/Chrome، اینترنت یا پورت محلی نیاز ندارد و Chromium را همراه خودش دارد.

اجرا
1) کل پوشه را استخراج کن (مثلاً C:\CodePad). فایل CodePad.exe باید کنار بقیهٔ فایل‌ها بماند.
2) روی CodePad.exe دوبار کلیک کن.
3) F11: تمام‌صفحه / بازگشت · F5 یا Ctrl+R: بارگذاری دوباره · اجرا با CodePad.exe --fullscreen: شروع تمام‌صفحه.
4) بستن پنجره = بستن برنامه. اجرای دوباره همان پروژه‌ها را نشان می‌دهد؛ اجرای دوم هنگام باز بودن، پنجرهٔ قبلی را جلو می‌آورد.

نیازها: Windows 10/11 x64. حدود ۶۰۰ مگابایت فضا پس از استخراج.

هشدار SmartScreen: فایل امضای دیجیتال ندارد؛ ویندوز ممکن است «Windows protected your PC» نشان دهد: More info ← Run anyway.

داده‌ها: پروژه‌ها و تنظیمات در %APPDATA%\CodePad ذخیره می‌شوند. برای پشتیبان از «مرکز پروژه» داخل برنامه استفاده کن. برای پاک‌کردن کامل، پوشهٔ همین مسیر را حذف کن.

تفاوت با اندروید (صادقانه)
- Python روی WebAssembly (Pyodide) اجرا می‌شود: سوکت، sqlite3 و thread واقعی ندارد. ربات‌هایی مثل ربات بله را با Python نصب‌شده روی ویندوز (python bale_bot.py) یا نسخهٔ اندروید اجرا کن.
- Termux و ابزارهای دستگاه (مکان، برنامه‌های نصب‌شده) فقط اندروید. ترمینال Cyber Lab اینجا فرمان اجرا نمی‌کند؛ تم، یادداشت‌ها، نمونه‌کدها و اتصال به هوش مصنوعی کار می‌کنند.
- اتصال به «سرور AI من»: سرور باید هدر CORS برای codepad://app بدهد (Access-Control-Allow-Origin).
- دوربین (ردیابی دست) با اجازهٔ دوربین ویندوز کار می‌کند.

آزمایش‌شده: همین برنامهٔ Electron روی لینوکس (پنجره، پایتون، input() زنده، ماندگاری داده، بدون پورت). روی ویندوز واقعی آزمایش نشده.

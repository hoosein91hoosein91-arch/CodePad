CodePad 3.7 (AI + Cyber) - نسخهٔ ویندوز / Windows edition
==========================================================

اجرا
1) کل پوشهٔ ZIP را در یک مسیر معمولی استخراج کن (مثلاً C:\CodePad). فقط CodePad.exe را بیرون نکش؛ پوشهٔ app باید کنارش بماند.
2) روی CodePad.exe دوبار کلیک کن. CodePad در یک پنجرهٔ Microsoft Edge (یا Google Chrome) باز می‌شود.
3) با بستن پنجره، برنامه هم کاملاً بسته می‌شود. اجرای دوباره همان پروژه‌ها را نشان می‌دهد.

نیازها
- Windows 10 یا 11 (x64) و Microsoft Edge یا Google Chrome (نسخهٔ ۱۳۷ یا بالاتر برای ورودی زنده با input()).
- اینترنت لازم نیست (به‌جز نصب کتابخانه‌های pip و Gemini / سرور AI تو).

هشدار SmartScreen
- این فایل امضای دیجیتال ندارد؛ ویندوز ممکن است بنویسد «Windows protected your PC». روی More info ← Run anyway بزن.
- فایل را فقط از منبعی که خودت ساخته‌ای/قبول داری اجرا کن.

داده‌ها کجاست؟
- پروژه‌ها و تنظیمات در پروفایل جدای مرورگر ذخیره می‌شوند: %LOCALAPPDATA%\CodePad\profile
- آدرس ثابت http://127.0.0.1:47831 است (برای ماندگاری داده). اگر آن پورت مشغول باشد، پورت بعدی (تا 47840) انتخاب می‌شود و داده‌ها جدا خواهند بود.
- برای پشتیبان‌گیری از «مرکز پروژه» داخل برنامه استفاده کن.

تفاوت با نسخهٔ اندروید (صادقانه)
- Python در این نسخه روی WebAssembly (Pyodide) اجرا می‌شود: سوکت، sqlite3 و thread واقعی ندارد. پروژه‌هایی مثل ربات بله را با Python نصب‌شده روی ویندوز اجرا کن (python bale_bot.py)، یا از نسخهٔ اندروید.
- Termux و ابزارهای دستگاه (مکان، برنامه‌ها) فقط در اندروید کار می‌کنند؛ ترمینال Cyber Lab اینجا فرمان اجرا نمی‌کند، اما تم، یادداشت‌ها، نمونه‌کدها و اتصال به هوش مصنوعی کار می‌کنند.
- اتصال به «سرور AI من»: سرور باید هدر CORS بدهد (مثلاً Access-Control-Allow-Origin: http://127.0.0.1:47831).

آزمایش‌نشده روی ویندوز واقعی: لانچر روی لینوکس با همان کد آزمایش شد و برای Windows کراس‌کامپایل شد.
